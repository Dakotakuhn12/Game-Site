# Game audio

These short WAV effects and the looping background track were generated for this game.

- `background.wav`: looping arcade-style melody
- `chomp.wav`: food pickup
- `power-pellet.wav`: power pellet pickup
- `ghost-eaten.wav`: ghost captured
- `death.wav`: life lost
- `fruit.wav`: bonus fruit pickup
- `level-up.wav`: maze cleared
- `extra-life.wav`: extra life earned

Playback is controlled by `../pacman-audio.js` and starts after the first game interaction.
